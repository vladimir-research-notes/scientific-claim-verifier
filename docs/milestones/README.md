# Milestone notes

One note per milestone, created by the milestone runner when the milestone
completes: `NN-<slug>.md` (e.g. `00-scaffold.md`).

Each note records:

- **Summary** — what the milestone establishes.
- **Deliverables** — files/subsystems added or changed.
- **Validation** — the exact commands run and their outcome.
- **Notes / decisions** — non-obvious choices and trade-offs.
- **Status** — Complete, and the next milestone.

See `docs/PLAN.md` section 9 for the milestone list.
