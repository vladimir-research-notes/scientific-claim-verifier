# Human-review placeholders

One placeholder per milestone: `NN-<slug>-human-review.md`. Created by the
milestone runner so a human can review asynchronously; the agent does **not**
claim that review happened. Structure:

```
Human review: <milestone title>
TL;DR
What changed
What should be checked later
Technical risks
Commands to verify
Human feedback
<!-- Human will fill this later. -->
```
