Milestones

The system is built incrementally by an autonomous Claude Code agent driven by scripts/run_all_milestones_with_claude.sh: one milestone per claude -p run, each committed locally with docs and website updated. Guards between milestones require a new commit, a clean tree, passing tests, and (once present) valid fixtures.

Build milestones

M0 — Scaffold & project contract planned

Python package skeleton (pyproject.toml, src/scientific_claim_verifier/ with __init__, cli, a schemas stub), console script claimverifier, scripts/00_check_environment.py, and the first CPU-only tests. Establishes a runnable, dependency-light baseline.

M1 — Core schemas planned

Typed pydantic models: ScientificClaim, ArtifactBundle, PaperArtifact, DatasetArtifact, CodeArtifact, EvidenceLink, VerificationCheck, VerificationResult, ReproductionStatus, SupportLabel, FailureMode, RunTrace, BenchmarkSuite, with unit tests.

M2 — Fixture tasks & validation planned

Small committed tasks (numeric table, dataset statistic, evidence passage, code reproduction, underspecified) with synthetic fixtures, plus scripts/01_validate_fixtures.py.

M3 — Rule-based claim extraction planned

Transparent extractors for numeric values, comparison phrases, metric names, dataset/table references, and passage IDs — a clearly-labelled heuristic baseline, tested against expected extracted claims.

M4 — Evidence linker planned

Exact passage lookup, a keyword-overlap baseline, table/dataset ID matching, and provenance records linking claims to the exact evidence.

M5 — Verification checks planned

Deterministic checks: table value, dataset statistic recomputation, numeric tolerance, comparison, evidence presence, and code execution for tiny scripts.

M6 — Reproducibility sandbox planned

Controlled execution for fixture code: temp dir, timeout, stdout/stderr/exit capture, no-network policy, and a trace record. Tests use harmless fixture scripts. Not an untrusted sandbox — see Limitations.

M7 — Scoring & failure modes planned

Support-label assignment, reproducibility-status assignment, failure-mode classification, aggregate summary, and per-claim result objects.

M8 — Smoke suite planned

8–15 verification tasks run fully offline; saved run traces, results, a summary CSV/JSON, and generated reports. Drives the Results page.

M9 — Reports planned

Markdown (+ optional HTML) reports from traces: input/extracted claim, evidence, checks, support label, reproducibility status, failure mode, limitations, and a trace link.

M10 — Optional adapters planned

RecordedLLMAdapter, MockLLMAdapter, and a cost-guarded ApiAdapterStub. Disabled by default; no paid API required.

M11 — Integration contracts planned

Compatible import/export formats for the code-agent runtime, BioScientist OS, BioAgentBench, LLM regression/observability, and agent-control-bench — without depending on those repos.

M12 — Portfolio report planned

README and docs to portfolio quality: problem, architecture, worked example, smoke-suite results, reproduction commands, limitations, and the future research path.

M13 — Final cleanup planned

Run tests, lint, fixture validation, the smoke suite, and report generation; verify no secrets/private papers/large data/caches/paid-API outputs and a clean tree; commit.

Each milestone also updates this website and writes its milestone, commit, and human-review notes under docs/. Statuses here flip to done as milestones complete.
