  reproduction_status   : approximately_reproduced

Report sections

Every generated report keeps the five channels separate — extracted claim, supporting text, computed check, inference, unverifiable — plus limitations and a link to the JSONL trace. The Markdown report is the default; an optional HTML report shares the same content.
